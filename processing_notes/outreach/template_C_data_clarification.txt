CLASS C — data clarification. Not a permissions request.

When you email, remember to:
1. cc itemresponsewarehouse@stanford.edu and bdomingue@stanford.edu
2. state the exact columns/values in question -- a vague question gets a vague
   answer, and these have usually already survived one round of guessing
3. say what you will do with each possible answer, so the cost of replying is
   one line rather than a conversation
4. log the send in processing_notes/outreach/outreach_log.csv
