# IRW permissions outreach

Tracked correspondence with rights-holders and depositors. See the GitHub
issue this directory was created for.

- `template_A_instrument_rights.txt` — permission to redistribute item WORDING
  (new; nothing covered this before).
- `template_C_data_clarification.txt` — a factual question about a deposit, not
  a permissions request.
- Class B (data licensing) keeps using `processing_notes/Licensing.txt`, which
  is already in service. Swap its OSF paragraph for the actual host.
- `outreach_log.csv` — standing, cumulative record of every send and every
  outcome, silence included. Never deleted.

**The log records correspondence, never licence state.** A grant flows to the
record that governs the decision: Class A to `itemtext/instrument_rights_register.csv`
(verdict flipped to `ship`, clause and source quoted), Class B to the biblio
`Original License` as `Permission via Email`. Do not let the log become a
second source of truth.

**Nothing here sends mail.** Drafts and ranking are prepared; a named person
sends them.
